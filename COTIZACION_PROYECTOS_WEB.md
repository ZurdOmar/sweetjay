## 🌐 EXPLICACIÓN DE HOSTING Y DOMINIO

### ¿Qué es el Dominio?

**Es la dirección de tu sitio web** (ej. `tudominio.com`)

| Característica | Detalle |
|----------------|---------|
| **Costo** | $300 - $500 MXN/año (.mx) |
| **Renovación** | Anual |
| **¿Quién lo paga?** | El cliente (es tuyo para siempre) |
| **¿Dónde se compra?** | GoDaddy, Namecheap, Google Domains |

**Ejemplos:**
- `doctorjuanperez.com`
- `psicologamaria.mx`
- `sweetjay.com.mx`

---

### ¿Qué es el Hosting?

**Es donde "vive" tu sitio web** (los archivos, imágenes, base de datos)

**Opciones disponibles:**

#### Opción 1: Firebase Hosting (Recomendado para sitios pequeños/medianos)

| Característica | Detalle |
|----------------|---------|
| **Proveedor** | Google (Firebase) |
| **Plan Gratuito** | ✅ Incluido (hasta ciertos límites) |
| **Límites gratis** | 10 GB almacenamiento, 360 MB/día transferencia |
| **Si excedes** | $0.50 - $5 USD/mes extra |
| **Ventajas** | Rápido, seguro, gratuito la mayoría del tiempo |
| **Ideal para** | Sitios con menos de 10,000 visitas/mes |

#### Opción 2: Hosting Compartido (SiteGround, Bluehost)

| Característica | Detalle |
|----------------|---------|
| **Costo** | $100 - $300 MXN/mes |
| **Ventajas** | Más control, correos incluidos |
| **Ideal para** | Sitios con WordPress o PHP |

#### Opción 3: Hosting Premium (VPS, Dedicado)

| Característica | Detalle |
|----------------|---------|
| **Costo** | $500 - $2,000+ MXN/mes |
| **Ventajas** | Máximo rendimiento, control total |
| **Ideal para** | Sitios con +50,000 visitas/mes |

## 📅 PROCESO DE TRABAJO

### Semana 1-2: Descubrimiento y Diseño

1. ✅ **Reunión inicial** (1-2 horas)
   - Conocer tu negocio/profesión
   - Definir objetivos del sitio
   - Revisar competencia
   - Recopilar contenido (fotos, textos, logos)

2. ✅ **Propuesta de diseño**
   - Mockup inicial (diseño en imagen)
   - Definir colores, tipografía, estilo
   - 2-3 rondas de revisiones

3. ✅ **Aprobación del diseño**
   - Firmas de aprobación
   - Se congela el diseño

### Semana 3-4: Desarrollo

4. ✅ **Desarrollo del Frontend**
   - Programación del sitio visible
   - Animaciones y efectos
   - Versión móvil y desktop

5. ✅ **Desarrollo del Backend**
   - Panel de administración
   - Base de datos
   - Integraciones (Calendly, etc.)

### Semana 5: Pruebas y Contenido

6. ✅ **Carga de contenido inicial**
   - Subir fotos, textos, servicios
   - Configurar redes sociales
   - Integrar Google Maps

7. ✅ **Pruebas internas**
   - Funcionalidad en todos los navegadores
   - Pruebas en móvil, tablet, desktop
   - Velocidad y rendimiento

### Semana 6: Entrega

8. ✅ **Revisión con el cliente**
   - Presentación del sitio
   - 1-2 rondas de ajustes finales

9. ✅ **Capacitación**
   - Cómo usar el panel de admin
   - Cómo subir contenido
   - Resolución de dudas

10. ✅ **Entrega oficial**
    - Firma de aceptación
    - Pago final
    - Inicio de garantía
